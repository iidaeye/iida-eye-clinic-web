## 涙道手術 (/surgery/lacrimal 用)

- 対象: 涙道閉塞・涙道狭窄による「なみだ目」
- 流れ: 涙道内視鏡検査で閉塞・狭窄の部位を確認 → 多くは涙管チューブ挿入術
- 涙管チューブの留置期間: 通常 約3か月
- 麻酔: 局所麻酔 (滑車下神経ブロック、涙道内麻酔、鼻内のリドカインスプレー)
- 涙嚢鼻腔吻合術が必要な場合: 静岡県立総合病院へ紹介し、同院の眼科涙道外来 (飯田裕子医師) と耳鼻咽喉科の合同で手術
- 執刀: 飯田裕子医師
- 手術日: 月曜午後。片側15〜30分程度。対象は鼻涙管閉塞・涙小管閉塞・涙点閉塞。小児の先天性鼻涙管閉塞は扱わない
- 費用は保険診療のため金額は載せない (院長方針)
- [要確認] 両側同日の可否、県立総合病院での入院の有無・日数
- 反映済み: /surgery/lacrimal

## 緑内障 (/surgery/glaucoma 用)

- 実施する術式: iStent、Hydrus マイクロステント、流出路再建術(眼内法)、プリザーフロマイクロシャント、線維柱帯切除術 (2026-10-13 聞き取り。clinic.json に反映済み)
- 呼び方: iStent・Hydrus・流出路再建術(眼内法) は「低侵襲緑内障手術(MIGS)」とまとめてよい。プリザーフロと線維柱帯切除術は「濾過手術」(院長指示 2026-10-13)
- 手術日は水曜、局所麻酔。濾過手術を含め全術式が日帰り (2026-10-13 確認)。執刀は主に飯田悠人
- 費用は保険診療のため金額は載せない (涙道・白内障と同じ方針)
- [要確認] 術式の使い分けの基準、iStent と Hydrus の使い分け、iStent の機種、流出路再建術の器具
- [要確認] 各術式の対象病型。プリザーフロ・線維柱帯切除術と白内障の同時手術の可否
- [要確認] 濾過手術の術後早期の通院間隔
- マイトマイシンC は濾過手術 (線維柱帯切除術) と PMS で使用 (2026-10-13 確認)
- [要確認] 麻酔の具体的な方法、手術時間 (単独/白内障同時)、両眼同日の可否と間隔
- [要確認] 術式ごとの抗凝固薬の休薬方針
- チューブシャント手術とレーザー治療 (SLT・LI) は当院では実施しない (2026-10-13 確認)
- [要確認] チューブシャント・レーザーが必要な場合の紹介先
